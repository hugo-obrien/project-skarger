# Project Skarger

Классическая изометрическая партийная CRPG (RTWP) в сеттинге тёмного фэнтези
на основе кельтской мифологии.

## 📖 Документация

Вся проектная документация находится в папке [`/Docs`](Docs/README.md):
- [Game Design Document](Docs/GDD/GDD.md)
- [Technical Design Documents](Docs/TDD/) (скоро)
- [Narrative Design Documents](Docs/NDD/) (скоро)

## 🛠 Технологии

- Unity (LTS)
- URP
- C# (.NET Standard 2.1)

## 📐 Принципы разработки

- SOLID, DRY, KISS, YAGNI
- Чистая архитектура
- Версионирование через Git
