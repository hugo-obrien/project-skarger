# Чек-лист ручных проверок (Unity Editor / Play Mode)

> Назначение: обязательный прогон после изменений ввода (инпут-система, контроллеры, ActionMaps)
> и перед сборкой/релизом. Отмечайте пункты `[x]` по мере прохождения.
> Обозначения: **П** — проверка в Play Mode, **E** — проверка в редакторе.

## 0. Подготовка (E)
- [ ] Проект открыт, окно **Console** без ошибок и предупреждений компиляции.
- [ ] Сцена `Assets/_Project/Scenes/00_Bootstrap.unity` запускается, затем автоматически загружает `SampleScene`.
- [ ] В настройках проекта включён **Input System Package (New)**, активный обработчик ввода — новый.

## 1. Инпут-система и GameControlsProvider (после 0.2)
- [ ] В Play Mode в иерархии есть объект `GameControlsProvider` ровно **один** (создаётся автоматически).
- [ ] Объект `GameControlsProvider` помечен `DontDestroyOnLoad` — при перезагрузке сцены не создаётся второй экземпляр.
- [ ] Повторный Play (Stop → Start) не даёт ошибок «leak», «Dispose asserted», NullReference в Console.
- [ ] `new GameControls()` вызывается только в `GameControlsProvider` (проверка grep по `Assets/_Project/Scripts`).
- [ ] Отключить/включить объект с `CameraController` несколько раз в Play Mode — зум мышью не ускоряется
      (значит, подписки `Zoom.performed` / `RotateMouseDelta.performed` не дублируются).
- [ ] После выхода из Play Mode в Console нет предупреждений Input System про незакрытые действия.

## 2. Камера (CameraController)
- [ ] **WASD / стрелки** — камера движется; направление совпадает с экраном (W — вперёд, S — назад, A/D — влево/вправо).
- [ ] **Q / E** — вращение камеры вокруг вертикальной оси (Q — влево, E — вправо).
- [ ] **Средняя кнопка мыши + движение** — вращение камеры; при отпускании кнопки вращение останавливается.
- [ ] **Колесо мыши** — приближение/отдаление с ограничениями min/max высоты (не проваливается под землю и не улетает бесконечно).
- [ ] **Края экрана** — камера скроллится к краю; над UI и при наведении на панель консоли скролл от края не работает.
- [ ] **Регрессия (редактор)**: Game → клик по панели редактора (Project/Console/Inspector) — камера стоит;
      клик по Game view — камера **не** едет (ни «несколько пикселей», ни «долгий дрейф» при удержании ЛКМ без движения);
      скролл от края возобновляется только когда мышь реально переместилась и находится у края Game view.
- [ ] При **открытой консоли** камера не реагирует на движение/зум/вращение.

## 3. Выбор юнитов (SelectionHandler)
- [ ] **ЛКМ по юниту фракции User** — юнит выделяется (маркер у ног).
- [ ] **Shift + ЛКМ по юниту** — добавление/снятие юнита из текущего выделения (toggle).
- [ ] **Рамка (зажать ЛКМ и протянуть)** — выделяются юниты User внутри рамки, маркеры у всех.
- [ ] **Рамка с Shift** — добавляют к текущему выделению, не сбрасывая его.
- [ ] **Рамка по пустому месту** — выделение сбрасывается.
- [ ] В рамках с врагами/нейтралами выбираются только юниты User; если в рамке только враги — выделяется ближайший
      к началу рамки враг (текущее поведение кода — подтвердить, что это желаемая механика).
- [ ] **Esc** — сброс выделения; очередь команд юнитов при этом продолжает выполняться (Esc не отменяет команды).

## 4. Команды / Action Queue (Move/Attack/Interact)
- [ ] **ПКМ по земле** — выбранные юниты идут в точку; маркер перемещения появляется и исчезает после прибытия.
- [ ] Несколько юнитов идут **формацией** (не слипаются, точки распределены).
- [ ] **ПКМ по врагу** — выбранные юниты атакуют цель.
- [ ] **ПКМ по союзнику/нейтралу** — юниты подходят на дистанцию взаимодействия, первый произносит приветствие
      (речевой пузырь «Hello, traveller!»).
- [ ] **Shift + ПКМ по земле** — команда добавляется в очередь: юнит выполняет первую точку, затем вторую, затем останавливается.
- [ ] **ПКМ по земле без Shift во время движения** — текущая команда отменяется, юнит идёт к новой точке.
- [ ] **Юнит в бою**: ПКМ по земле — юнит выходит из боя и идёт (фикс бага 0.1 — пользовательская команда не перебивается AI).
- [ ] Смена команды во время боя **не сбрасывает кулдаун атаки** (фикс бага 0.1).
- [ ] **Смерть юнита** — очередь команд очищается, юнит останавливается, выделение снимается.
- [ ] Повторный ПКМ по уже атакующему юниту — команда атаки не «застревает» (нет дублей в очереди).

## 5. Бой и юниты
- [ ] **Ближний бой**: юнит подходит в диапазон, проигрывает анимацию атаки, урон наносится по таймингу анимации.
- [ ] **Дальний бой**: при анимации срабатывает `SpawnProjectile`, снаряд летит в цель и наносит урон;
      если профиль без префаба снаряда — мгновенный урон (в Console предупреждение).
- [ ] Повторная атака работает (кулдаун соблюдается), юнит не «застревает» в состоянии атаки.
- [ ] **Смерть**: HP → 0, коллайдер отключается, проигрывается анимация смерти, через `deathAnimationDuration`
      включается ragdoll (или аниматор отключается); юнит нельзя снова выделить/атаковать, маркер скрыт.
- [ ] **AI**: враг с `aiControlled` сам находит цель в `perceptionRadius` (визуально — синий гизмо-круг в редакторе),
      атакует; при получении урона отвечает атакующему.
- [ ] AI не перебивает пользовательские команды (юнит под управлением игрока продолжает выполнять команду, если его бьют).
- [ ] **Фракции**: User/Allied/Enemy — враждебность по `FactionRelations`; Neutral не враждебен никому;
      Allied и Enemy — враги. Проверить хотя бы User↔Enemy и Allied↔Neutral.

## 6. Время (GameTimeManager)
- [ ] **Space** — пауза: движение/бой/анимации замирают; **повторный Space** — продолжение.
- [ ] **Tab** — переключение скорости 1 → 1.5 → 2 → 1; движение/анимации ускоряются.
- [ ] Смена скорости на паузе сохраняется: после снятия паузы применяется новое значение.
- [ ] После перезапуска плейтеста `Time.timeScale == 1` (нет «залипшей» паузы).

## 7. Консоль (DebugConsole)
- [ ] **` (backquote)** — открытие/закрытие консоли.
- [ ] При открытой консоли игровые действия (выбор, команды, камера) не срабатывают.
- [ ] **Escape** при открытой консоли — закрывает консоль (и не сбрасывает выделение).
- [ ] `help` — выводит список доступных команд.
- [ ] `damage 100` — наносит 100 урона выделенным юнитам; `damage` без аргументов — 50.
- [ ] `message Привет` — выбранные юниты показывают речевой пузырь с текстом.
- [ ] Неизвестная команда и кривые аргументы — сообщение об ошибке, без исключений.
- [ ] Консоль переживает смену сцены; после повторного Play нет двух экземпляров консоли.

## 8. DevSpawner (dev-инструменты)
- [ ] **F1 / F2 / F3 / F4** — спавн юнита User / Allied / Neutral / Enemy в точке под курсором.
- [ ] Заспавненный юнит появляется на земле (не в полу), стоит на NavMesh и может двигаться.
- [ ] Заспавненного User можно выделить и отдать команду; враг (F4) — не выделяется игроку, атакуем ПКМ.

## 9. Геймпад (известный пробел)

      пункты 1–8 с геймпадом: выбор, команды, камера, пауза/скорость, консоль.
