### 0.2 Вынести GameControls в один компонент ✅
**Статус:** выполнено. Единый экземпляр `GameControls` создаётся и переживает смену сцены в `GameControlsProvider` (`Assets/_Project/Scripts/Systems/GameControlsProvider.cs`); все контроллеры получают его через `GameControlsProvider.Instance.Controls`.

Каждый контроллер создаёт свой экземпляр GameControls. Работает, но лучше вынести общий экземпляр в один компонент.

## Спринт 1: Foundation Systems (Фундаментальные системы)
### 1.0 Система загрузки конфигураций
**Цель:** Система, позволяющая создавать, редактировать и хранить данные о сущностях игры в формате, удобном для работы (CSV, JSON)

**Задачи**
- Продумать систему сущностей и их сериализации/десериализации
- Реализовать загрузку сущностей для работы с ними в редакторе и внутри игры.
- Реализовать систему маппинга игровых сущностей на текстовые id (addressables?)

### 1.1 Система снаряжения (инвентарь)
**Цель:** Базовая система инвентаря и экипировки

**Задачи:**
- Создать Inventory компонент для персонажей
- Реализовать Item и ItemStack классы
- Создать систему слотов экипировки (оружие, броня, кольца) - _уточнение: пока без визуальной части, т.е. без настройки 
слотов на модели, отображения, анимаций и т.д. Визуальную часть функционала на время разработки реализовать через систему
иконок над/сбоку от персонажа_
- Реализовать EquipmentEffects - как снаряжение влияет на статы
- Создать базовый UI инвентаря (сетка, drag-and-drop)

### 1.2 Система "Органичного Мастерства"
**Цель:** Реализовать базовую систему прогрессии через действия

**Задачи:**
- Создать SkillNode, SkillTree, ConditionEvaluator (согласно ГДД п. 4.2.1)
- Реализовать ProgressionTracker - слушатель событий (OnDamageDealt, OnSpellCast, OnSkillUsed)
- Создать систему "тумана войны" для дерева навыков (видны только активные узлы)
- Реализовать формулу экспоненциальной прокачки: XpToNext = BaseXp * (CurrentLevel ^ 1.5) * DifficultyMultiplier
- Создать UI для отображения дерева навыков (базовая версия)

**Архитектура (SOLID):**
```
ISkillSystem (интерфейс)
├── SkillNode (узел навыка)
├── SkillTree (дерево навыков персонажа)
├── ConditionEvaluator (проверка условий разблокировки)
└── ProgressionTracker (слушатель событий)
```

### 1.3 RTWP Боевая система - Action Queue
**Цель:** Реализовать очередь команд и полноценную паузу

**Задачи:**
- Создать ActionQueue - очередь команд для каждого персонажа ✅ **Выполнено**
- Реализовать систему паузы с заморозкой времени (уже есть GameTimeManager, но нужно улучшить) - _Были доработки, нужно
повторное исследование_
- Создать UI для отображения очереди команд (иконки действий над персонажами)
- Добавить назначаемые горячие клавиши для навыков (1-0) - _Были доработки, нужно повторное исследование_
